# Herramientas

- `sync-40kdc.py`: actualiza el respaldo JSON desde una revisión inmutable del repositorio de datos.
- `editor-server.mjs`: servidor estático local de solo lectura; conserva el nombre por compatibilidad con comandos anteriores.

Se retiraron los scripts de detección/calibración de imágenes porque los mapas ahora proceden de geometría estructurada.

Las herramientas opcionales de auditoría de los símbolos oficiales están en `integrations/40kdc/tools/`; consulta su README antes de usarlas con otro PDF.
